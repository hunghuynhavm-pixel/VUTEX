Hiểu 2 cái này là hiểu 80%

raw/ và wiki/ là gì?

📥 raw/ — Kho ĐẦU VÀO

Chỗ bạn bỏ tài liệu vào. Không cần sắp xếp, không cần đặt tên đẹp.

  • Ghi chú sau buổi học
  • Bài viết hay, PDF, ảnh chụp
  • Ý tưởng chợt nảy ra
  • Transcript video, podcast
📚 wiki/ — Kho KẾT QUẢ

Claude đọc raw/ rồi tự tạo file gọn gàng. Bạn không phải tự viết gì.

  • learn/ — tóm tắt khoá học
  • work/ — kế hoạch, dự án
  • people/ — thông tin về người
  • life/ — sức khoẻ, tài chính

Bước 1 — Cài Obsidian

App để xem & quản lý ghi chú

1
Vào obsidian.md → bấm nút Download lớn.
2
Chọn đúng hệ điều hành (Mac / Windows).
3
Mở file → Next liên tục → Finish.
✅Mở thử thấy màn hình hỏi tạo vault → đóng lại, chưa cần làm gì.
Bước 2 — Cài Node.js

Cái nền để Claude Code chạy được

1
Vào nodejs.org.
2
Bấm nút xanh lớn có chữ LTS.
3
Mở file → Next → Install → Finish.
⚠️Cài xong không có icon app mới — Node chạy ngầm. Hoàn toàn bình thường.
⚙️
Bước 3 — Cài Claude Code

Nhân vật chính: AI tạo wiki

Mở Terminal (Mac: ⌘+Space → “Terminal”. Windows: Start → “cmd”), rồi dán 1 lệnh:

Terminal
$ npm install -g @anthropic-ai/claude-code
added 47 packages in 8s   ← thấy dòng này là xong

$ claude --version
1.x.x   ← có số phiên bản = cài thành công
💡Từ đây Claude làm được mọi thứ cho bạn: bước nào phía sau thấy khó, cứ hỏi thẳng nó.
Bước 4 — Cài Git

Chiếc “nút hoàn tác” cho cả vault

1
Vào git-scm.com → Download → mở file → Next → Install.
2
Kiểm tra: Terminal gõ git --version → thấy 2.x.x.
🍎Máy Mac: lần đầu có thể hiện popup cài “Command Line Tools” → bấm Install là xong (cũng là cách cài Git nhanh nhất).
🕘
Bước 5 & 6 — Vault & kết nối

Tạo thư mục rỗng, rồi mở trong Obsidian

📁 Bước 5 — Tạo vault

Ra Desktop → tạo thư mục mới, ví dụ “Bộ não của Minh”.

Không tạo gì bên trong, không tải file nào. Để trống hoàn toàn.

🔗 Bước 6 — Kết nối Obsidian

Mở Obsidian → “Open folder as vault” → chọn thư mục → Open.

Giao diện 2 cột hiện ra, vault còn trống — hoàn toàn bình thường.

Lần đầu mở Claude Code

Mở đúng thư mục → dán câu lệnh setup

1
Mac: chuột phải thư mục vault → “New Terminal at Folder”.  Windows: mở thư mục → chuột phải khoảng trống → “Open in Terminal”.
2
Gõ claude → Enter. Cửa sổ chat hiện ra.
3
Dán toàn bộ câu lệnh setup (trong mô tả video) → Enter → ngồi xem.
